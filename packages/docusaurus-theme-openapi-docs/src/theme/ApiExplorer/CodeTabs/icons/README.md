# Code snippet language icons

These SVGs are vendored from [devicon](https://github.com/devicons/devicon)
(MIT License), v2.17.0. They were previously hot-linked from
`raw.githubusercontent.com`, which serves `.svg` files as `text/plain` with
`X-Content-Type-Options: nosniff` — so browsers download them (HTTP 200) but
refuse to render them as images. Bundling them locally makes icon rendering
independent of GitHub's raw-content headers and network access.

File names map to the `logoClass` used in `_CodeTabs.scss` selectors.
